# Web Design

Collection slug: `web-design`

Active Skills: **90**

## Purpose

Portable workflows for designing and implementing browser-based visual, interactive, cinematic, and scroll-driven experiences.

## Boundary

Generic engineering belongs in software-engineering; non-site visual artifacts belong in visual-content.

## Contract

- `skills/` contains the canonical active Skill folders owned by this collection.
- `registry.md` records provenance, hashes, status, and compatibility.
- `LICENSES.md` records exact licence evidence and Owner exceptions.
- Packages are produced in external staging and published as immutable artifacts; their URLs and checksums are recorded under `logs/releases/`.

Apply the repository-root `COLLECTIONS_STANDARD.md`, `INGESTION_STANDARD.md`, `PORTABILITY_STANDARD.md`, and `PRODUCTION_STANDARD.md`. Do not copy a Skill into another collection; record cross-domain relevance in the registry instead.
