# Skill Collections

This directory is the canonical home for domain-organized Skills. Read [`../COLLECTIONS_STANDARD.md`](../COLLECTIONS_STANDARD.md) before adding, moving, packaging, or releasing any Skill.

Approved category slugs and machine-readable meanings are stored in [`catalog.json`](catalog.json). Collection directories are created only when they receive an approved Skill or an explicit migration; empty category directories are not required.

The active collection inventory is [`index.md`](index.md). Current active collections are `software-engineering`, `web-design`, and `visual-content`.

The root `skills/` and `dist/` directories are legacy history. They are not templates for new collections.
