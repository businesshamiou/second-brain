# Visual Content

Collection slug: `visual-content`

Active Skills: **2**

## Purpose

Portable workflows for diagrams, storyboards, illustration systems, and visual explanation outside complete website implementation.

## Boundary

Complete browser experiences belong in web-design; media rendering and transformation pipelines belong in media-production.

## Contract

- `skills/` contains the canonical active Skill folders owned by this collection.
- `registry.md` records provenance, hashes, status, and compatibility.
- `LICENSES.md` records exact licence evidence and Owner exceptions.
- `releases/` contains immutable versioned packages produced from the active tree.

Apply the repository-root `COLLECTIONS_STANDARD.md`, `INGESTION_STANDARD.md`, `PORTABILITY_STANDARD.md`, and `PRODUCTION_STANDARD.md`. Do not copy a Skill into another collection; record cross-domain relevance in the registry instead.
