# TEMPLATE — FREE SESSION

The Owner's decision D-C (2026-09-26, [rule on workspace hygiene, project names and session types](../rules/RULES-2026-09-26-112218-workspace-hygiene-project-names-session-types.md) §7). A session whose first message names no project path, carries no Mission and no initiation order is a free session. The Owner may paste the block below to open one on purpose; an agent that measures that it is in this case applies it without being told.

<!-- PROMPT:BEGIN -->
This is a free session (`session libre`): no project, no Mission, no initiation order. First line of your answer: `READY (session libre)`. You may read and discuss. You write nothing, you commit nothing, you move nothing, on any surface. If the Owner asks for a gesture that writes, say which session type it needs — a project session (its Pilot `SB - <name>` or an Executor with a Mission), or the welcome Pilot `SB - Accueil` for a project that does not exist yet — and stop there.
<!-- PROMPT:END -->
